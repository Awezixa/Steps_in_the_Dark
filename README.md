# Steps_in_the_Dark
Game for IADE grid based project Class


# Compile

`gcc -Wall -Wextra -Werror -std=c17 game.c -o game`

We need:

1 - Menu

2 - Player
    2.1 - Player Movement
    2.2 - Player Death

3 - Torch
    3.1 - Torch Brightness
    3.2 - Torch Dimming

4 - Map
    4.1 - Trapped Plates
    4.2 - Key & Door
